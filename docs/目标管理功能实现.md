# 目标管理功能实现说明

## 概述

为舰载机控制终端添加了目标管理功能，支持删除指定目标和清除所有目标。

## 新增内容

### 1. 网络包：`ManageTargetsPayload`

**位置**: `com.indomitable.carrieraircraft.network.ManageTargetsPayload`

**功能**: 
- 客户端 → 服务端的目标管理命令
- 支持两种操作：
  - `CLEAR_ALL`: 清除所有目标
  - `REMOVE_BY_INDEX`: 删除指定索引的目标

**参数**:
- `action`: 操作类型（枚举）
- `targetIndex`: 目标索引（0-based，仅在删除单个目标时使用）

### 2. 火控系统方法：`FireControlSystem.removeTarget()`

**位置**: `com.indomitable.carrieraircraft.firecontrol.FireControlSystem`

**功能**: 按索引删除目标

**方法签名**:
```java
public boolean removeTarget(UUID playerUUID, int index)
```

**返回值**: 
- `true`: 删除成功
- `false`: 索引无效或目标不存在

### 3. 网络包注册

**位置**: `com.indomitable.carrieraircraft.event.CommonModEvents.registerPayloads()`

已在网络包注册器中注册 `ManageTargetsPayload`。

## 使用说明

### 客户端 GUI 调用示例

在控制终端 GUI 中，可以通过以下方式发送目标管理命令：

#### 删除指定目标
```java
// 删除第 2 个目标（索引 1）
PacketDistributor.sendToServer(new ManageTargetsPayload(
    ManageTargetsPayload.Action.REMOVE_BY_INDEX, 
    1
));
```

#### 清除所有目标
```java
PacketDistributor.sendToServer(new ManageTargetsPayload(
    ManageTargetsPayload.Action.CLEAR_ALL, 
    -1  // targetIndex 在 CLEAR_ALL 时被忽略
));
```

## 服务端处理流程

1. **验证权限**: 检查玩家是否打开了控制终端 GUI
2. **执行操作**:
   - `CLEAR_ALL`: 调用 `FireControlSystem.clearTarget(playerUUID)`
   - `REMOVE_BY_INDEX`: 调用 `FireControlSystem.removeTarget(playerUUID, index)`
3. **发送反馈**: 向玩家发送操作结果消息

## 消息提示

- 删除单个目标成功: "已删除目标 #N" (绿色)
- 删除单个目标失败: "目标不存在" 或 "无效的目标索引" (红色)
- 清除所有目标成功: "已清除所有目标" (绿色)

## 技术细节

### 目标索引规则

- 索引从 0 开始
- 最多支持 4 个目标（`FireControlSystem.MAX_TARGETS = 4`）
- 删除目标后，列表自动收缩，不留空位
- 索引越界返回 `false`，不抛出异常

### 线程安全

所有网络包处理都在主线程（`context.enqueueWork()`）中执行，确保线程安全。

### 性能考虑

- 删除操作时间复杂度：O(1)（ArrayList.remove）
- 清除操作时间复杂度：O(1)（HashMap.remove）
- 无需担心性能问题，目标数量最多 4 个
