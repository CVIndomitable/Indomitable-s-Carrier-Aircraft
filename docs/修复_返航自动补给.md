# 修复：返航自动补给功能

**修复日期**: 2026-07-10
**影响范围**: 飞机回收流程
**问题严重度**: 中等（游戏性影响）

## 问题描述

在之前的实现中，舰载机返航回收时**不会自动补给弹药**，导致以下问题：

1. **弹药浪费**：飞机消耗部分弹药后返航，回收时剩余弹药直接丢失
2. **补给方法未被调用**：`rearmFromInventory()` 方法已实现但从未被调用
3. **不符合设计意图**：按照策划方案，返航应该自动补给后再回收

## 根本原因

`AircraftEntity.tickReturning()` 方法在靠近玩家时直接调用 `toStack()` 转为物品并回收，**跳过了补给环节**。

补给逻辑 `rearmFromInventory()` 已经完整实现（支持创造模式/普通模式、弹匣合并等），但没有任何地方调用它。

## 修复内容

修改 `AircraftEntity.tickReturning()` 方法（第 402-414 行）：

### 修改前
```java
if (distToOwner < COLLECT_RANGE + spec.standbyHeight() * 0.1) {
    ItemStack stack = toStack();
    if (owner.getInventory().add(stack)) {
        owner.sendSystemMessage(Component.literal(String.format(
                "已回收 %s（对海 %d/%d，对空 %d/%d）",
                getRole().displayName(),
                seaWeaponSlot.count(), seaWeaponSlot.capacity(),
                airWeaponSlot.count(), airWeaponSlot.capacity()
        )).withStyle(ChatFormatting.GREEN));
        discard();
    }
}
```

### 修改后
```java
if (distToOwner < COLLECT_RANGE + spec.standbyHeight() * 0.1) {
    // 先自动补给
    boolean rearmed = rearmFromInventory(owner);

    ItemStack stack = toStack();
    if (owner.getInventory().add(stack)) {
        // 消息显示补给后的弹药状态
        Component msg = Component.literal(String.format(
                "已回收 %s（对海 %d/%d，对空 %d/%d）%s",
                getRole().displayName(),
                seaWeaponSlot.count(), seaWeaponSlot.capacity(),
                airWeaponSlot.count(), airWeaponSlot.capacity(),
                rearmed ? " [已补给]" : ""
        )).withStyle(rearmed ? ChatFormatting.GOLD : ChatFormatting.GREEN);
        owner.sendSystemMessage(msg);
        discard();
    }
}
```

## 修复效果

1. **自动补给**：飞机返航时自动从玩家背包中消耗弹药物品补满
2. **视觉反馈**：
   - 补给成功时消息显示 `[已补给]` 标签，文字为金色
   - 未补给时（背包无弹药或已满弹）消息保持绿色
3. **显示准确弹药**：消息中的弹药数量是**补给后**的状态

## 补给逻辑说明

`rearmFromInventory()` 方法的行为（已存在，此次修复仅调用）：

- **创造模式**：直接补满，不消耗物品
- **普通模式**：
  - 遍历玩家背包中的 `AviationAmmoItem`
  - 按弹药类型匹配对海槽和对空槽
  - 消耗物品填充武器槽至满载
  - 支持弹匣部分消耗（如弹匣剩余 50 发，飞机需要 30 发，则消耗 30 发并保留剩余 20 发的弹匣）

## 测试建议

1. **基础补给**：飞机消耗部分弹药后返航，背包中有对应弹药物品，验证自动补给并消耗物品
2. **创造模式**：创造模式下返航，验证不消耗物品直接补满
3. **背包无弹药**：背包中无弹药时返航，验证不补给且消息无 `[已补给]` 标签
4. **弹匣部分消耗**：对空槽未满时返航，背包中有部分满的弹匣，验证弹匣正确合并
5. **满弹返航**：飞机满弹返航，验证不消耗物品且消息无 `[已补给]` 标签
