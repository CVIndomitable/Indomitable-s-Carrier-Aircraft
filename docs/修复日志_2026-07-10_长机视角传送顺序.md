# 修复日志：长机视角切换时的传送顺序问题

**日期**：2026-07-10  
**类型**：Bug 修复  
**优先级**：高  
**状态**：已修复

## 问题

玩家从长机视角切回自身视角时，有时会被传送到飞机所在位置，而不是回到进入视角前的位置。

## 根本原因

`CommandPayload.exitLeaderCamera()` 中的调用顺序错误：

```java
// ❌ 错误顺序
player.setCamera(player);                                    // 先切换摄像机
CameraStateTracker.getInstance().exitLeaderCamera(player);  // 再传送
```

当 `setCamera(player)` 被调用时，客户端立即将摄像机切换到玩家的**当前位置**。如果此时玩家实体位置由于网络同步问题已接近飞机位置（或直接在飞机位置），客户端会看到玩家在飞机处，即使之后执行传送也已造成视觉闪烁和位置异常。

## 解决方案

**修改文件**：`CommandPayload.java:196-200`

将调用顺序反转：

```java
// ✅ 正确顺序
CameraStateTracker.getInstance().exitLeaderCamera(player);  // 先传送玩家回原位置
player.setCamera(player);                                    // 再切换摄像机
```

这样可以确保摄像机切换时，玩家已经在正确的位置。

## 技术细节

- `CameraStateTracker.exitLeaderCamera()` 内部调用 `player.teleportTo()`，会立即发送位置同步包到客户端
- `player.setCamera()` 触发客户端摄像机切换，使用玩家当前位置
- 先传送后切换可避免客户端在错误位置看到玩家实体

## 测试建议

1. 进入长机视角，等飞机飞远（100+ 格）
2. 从控制终端切回玩家视角
3. 验证玩家位置在进入视角前的原地，而非飞机位置
4. 多次快速切换视角，确认没有位置跳变
