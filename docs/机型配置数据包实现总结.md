# 机型配置数据包系统 - 实现总结

**实施日期**: 2026-07-02  
**状态**: ✅ 已完成并验证

## 概述

将机型配置从硬编码改为 JSON 数据包驱动，实现"新增机型不改代码"的设计目标。

## 实现内容

### 1. 核心加载器 (`AircraftSpecLoader.java`)

- 继承 `SimpleJsonResourceReloadListener`，集成 NeoForge 数据包系统
- 数据包路径：`data/<namespace>/aircraft/<aircraft_id>.json`
- 支持内置默认值 + 数据包覆盖/扩展
- 完整的 JSON 解析和错误处理
- 枚举类型容错（无效值记录警告但不阻止加载）

### 2. 内置机型 JSON 配置

创建了 4 个内置机型的 JSON 配置文件：

- `data/indomitablecarrieraircraft/aircraft/b25.json` - B-25 水平轰炸机
- `data/indomitablecarrieraircraft/aircraft/btd.json` - BTD 俯冲轰炸机/鱼雷机
- `data/indomitablecarrieraircraft/aircraft/rocket_attacker.json` - 火箭攻击机
- `data/indomitablecarrieraircraft/aircraft/asw_patrol.json` - 反潜巡逻机

所有参数与原硬编码值完全一致，确保行为兼容。

### 3. 代码重构

**修改的文件**：
- `CommonModEvents.java` - 注册数据加载监听器
- `AircraftSpawnerItem.java` - 使用加载器获取机型配置
- `AircraftEntity.java` - 使用加载器获取默认配置

**保留的硬编码**：
- `AircraftSpec.B25/BTD/ROCKET_ATTACKER/ASW_PATROL` 常量保留作为 fallback
- 仅在数据包加载失败或服务器启动初期使用

### 4. 文档

- `docs/aircraft_datapack.md` - 完整的数据包格式说明
- `docs/aircraft_datapack_examples.md` - 3 个实用示例（自定义机型、修改现有机型、重型轰炸机）
- `README.md` - 添加数据包支持说明

## 特性

✅ **热重载**: 使用 `/reload` 命令即可重新加载机型配置，无需重启游戏  
✅ **容错性**: 内置默认值确保数据包缺失时模组仍可正常工作  
✅ **可扩展**: 数据包可以添加新机型或覆盖现有机型  
✅ **完整日志**: 加载过程记录详细日志，便于调试  
✅ **错误处理**: JSON 解析错误不会导致崩溃，会记录错误并跳过该文件

## 技术细节

### 加载顺序

1. 服务器启动时触发 `AddReloadListenerEvent`
2. `AircraftSpecLoader.apply()` 被调用
3. 先加载内置 4 个默认机型
4. 然后加载所有数据包中的 JSON 文件
5. 数据包配置可以覆盖内置机型（相同 ID）

### 查询 API

```java
// 获取加载器实例
AircraftSpecLoader loader = AircraftSpecLoader.getInstance();

// 根据 ID 获取机型配置
AircraftSpec spec = loader.getSpec("b25");

// 根据角色获取默认 ID
String id = AircraftSpecLoader.getDefaultIdForRole(AircraftRole.BOMBER);

// 检查机型是否存在
boolean exists = loader.hasSpec("custom_aircraft");

// 获取所有已加载的机型 ID
Set<String> ids = loader.getAllSpecIds();
```

### 命名约定

- JSON 文件名即为机型 ID（不含扩展名）
- 建议使用小写字母和下划线：`heavy_bomber.json`
- 避免使用特殊字符和空格

## 向后兼容性

- `AircraftSpec` 的静态常量保留，旧代码仍可编译
- NBT 序列化/反序列化格式不变
- 存档中已生成的飞机实体不受影响

## 已知限制

1. **物品注册未动态化**: 召唤物品仍需手动注册，无法通过数据包自动生成
2. **渲染器未动态化**: 自定义机型使用默认渲染器
3. **本地化未集成**: 机型名称和描述需要手动添加到语言文件

这些限制可在后续版本中改进。
