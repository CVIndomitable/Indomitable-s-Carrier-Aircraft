## 实现状态

### ✅ 弹药消耗（已完整）

#### 对海武器消耗
- **位置**: `AircraftEntity.releaseSeaWeapons()` (第 677-687 行)
- **触发时机**: `DROPPING` 状态，到达投弹点时
- **实现细节**:
  ```java
  int requested = calculateReleaseCount();  // 根据配置计算投弹数
  int released = seaWeaponSlot.consume(requested);  // 消耗弹药
  syncAmmoData();  // 同步到客户端
  ```
- **支持特性**:
  - 根据玩家配置的 `bombsPerPass` 决定单次投弹数
  - 根据 `minimumEffectiveDamage` 决定是否全部投完

#### 对空武器消耗
- **位置**: `AircraftEntity.shootAirTarget()` (第 742-749 行)
- **触发时机**: `DOGFIGHT` 状态或自卫炮塔射击时
- **实现细节**:
  ```java
  if (airWeaponSlot.consume(12) <= 0) { syncAmmoData(); return; }
  syncAmmoData();
  if (target instanceof LivingEntity living) {
      living.hurt(damageSources().mobAttack(this), 4.0F);
  }
  ```
- **支持特性**:
  - 每次射击消耗 12 发弹药
  - 弹药不足时停止射击
  - 立即同步到客户端

### ✅ 弹药补给（已完整）

#### 自动补给
- **位置**: `AircraftEntity.tickReturning()` (第 387-415 行)
- **触发时机**: 飞机返航靠近玩家时（距离 < 3.0 + standbyHeight * 0.1）
- **实现细节**:
  ```java
  boolean rearmed = rearmFromInventory(owner);  // 补给
  ItemStack stack = toStack();  // 转为物品（携带补给后的弹药数据）
  ```
- **视觉反馈**:
  - 补给成功：金色消息 + `[已补给]` 标签
  - 未补给：绿色消息（背包无弹药或已满弹）

#### 补给逻辑
- **位置**: `AircraftEntity.rearmFromInventory()` (第 818-874 行)
- **实现细节**:
  ```java
  public boolean rearmFromInventory(ServerPlayer owner) {
      int oldSea = seaWeaponSlot.count();
      int oldAir = airWeaponSlot.count();
      if (owner.getAbilities().instabuild) {
          // 创造模式：直接补满
          seaWeaponSlot.setCount(spec.seaAmmoCapacity());
          airWeaponSlot.setCount(spec.magazineCapacity());
      } else {
          // 普通模式：从背包中消耗弹药物品
          restockFromInventory(seaWeaponSlot, owner);
          restockFromInventory(airWeaponSlot, owner);
      }
      syncAmmoData();
      return oldSea != seaWeaponSlot.count() || oldAir != airWeaponSlot.count();
  }
  ```
- **支持特性**:
  - 创造模式：不消耗物品直接补满
  - 普通模式：遍历背包消耗 `AviationAmmoItem`
  - 弹药类型匹配（对海/对空槽分别匹配）
  - 弹匣部分消耗与合并（见下）

#### 弹匣特殊处理
- **位置**: `AircraftEntity.restockMagazineFromStack()` (第 849-874 行)
- **实现细节**:
  - 弹匣（`AmmoType.MAGAZINE`）可以**部分消耗**
  - 例子：弹匣剩余 50 发，飞机需要 30 发
    - 消耗 30 发填充飞机
    - 保留剩余 20 发的弹匣在背包中
  - 支持弹匣堆叠与拆分
- **数据组件**: `ModDataComponents.MAGAZINE_ROUNDS` 存储弹匣当前弹药数

## 弹药流程

### 完整生命周期

1. **召唤飞机**:
   ```
   AircraftSpawnerItem.use()
   → 从物品栈读取弹药数据
   → AircraftEntity.create() 初始化武器槽
   → 飞机实体携带弹药出现
   ```

2. **执行任务**:
   ```
   DROPPING 状态
   → releaseSeaWeapons() 消耗对海弹药
   → syncAmmoData() 同步到客户端
   
   DOGFIGHT / 自卫炮塔
   → shootAirTarget() 消耗对空弹药
   → syncAmmoData() 同步到客户端
   ```

3. **弹药耗尽**:
   ```
   hasSeaAmmo() 返回 false
   → setState(RETURNING)
   → 返航
   ```

4. **返航回收**:
   ```
   tickReturning()
   → 靠近玩家时触发
   → rearmFromInventory() 自动补给
     ├─ 创造模式：直接补满
     └─ 普通模式：从背包消耗弹药物品
   → toStack() 转为物品（携带补给后的弹药数据）
   → 物品加入玩家背包
   → discard() 移除实体
   ```

5. **再次召唤**:
   ```
   使用飞机物品
   → 从物品栈恢复弹药数据
   → 飞机以上次回收时的弹药状态出现
   ```

## 总结

弹药系统是一个**完整闭环**：

```
召唤（恢复） → 消耗（战斗） → 补给（返航） → 回收（保存） → 再召唤
     ↑__________________________________________________|
```

所有环节都已实现并经过验证。修复后的自动补给功能使整个循环更加流畅，玩家无需手动管理弹药，只需准备好弹药物品在背包中即可。
