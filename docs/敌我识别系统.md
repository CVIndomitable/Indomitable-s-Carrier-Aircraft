# 敌我识别系统

## 概述

`FriendlyFireFilter` 提供多层次的敌我识别机制，确保舰载机正确区分友军和敌军，避免误伤。

## 识别规则（按优先级）

### 1. 实体类型标签（最高优先级）

玩家可通过数据包自定义友敌关系：

- **友方白名单**：`data/indomitablecarrieraircraft/tags/entity_type/friendly_entities.json`
- **敌对黑名单**：`data/indomitablecarrieraircraft/tags/entity_type/hostile_entities.json`

标签中定义的实体类型将覆盖所有其他规则。

**默认友方实体**：
- 村民、铁傀儡
- 驯服的动物（猫、狼、鹦鹉、马等）
- 雪傀儡、悦灵

**默认敌对实体**：
- 所有原版怪物（僵尸、骷髅、苦力怕、幻翼等）
- 掠夺者、卫道士、唤魔者
- 守卫者、潜影贝

### 2. 所有者识别

- 飞机不会攻击自己的所有者（召唤者）
- 飞机不会攻击同所有者的其他召唤物（其他飞机、驯服的狼等）
- 不同玩家的飞机互不攻击（除非通过队伍或标签明确标记为敌对）

### 3. 队伍系统

使用 Minecraft 原版的队伍系统（`/team`）：

- 同队伍的玩家及其召唤物为友方
- 队伍设置 `friendlyFire=false` 时，禁止攻击队友
- 队伍设置 `friendlyFire=true` 时，交由默认规则判断

**用法示例**：
```mcfunction
# 创建队伍
/team add allies
/team modify allies friendlyFire false

# 加入队伍
/team join allies @a
```

### 4. 默认规则（最低优先级）

当以上规则都无法判断时，使用默认规则：

- 实现 `Enemy` 接口的实体 → 敌对
- `Animal`（被动生物）、`Villager`（村民）→ 友方
- `Player`（玩家）→ 友方（PvP 需通过队伍或标签控制）
- 其他未定义实体 → 友方（默认不攻击）

## 应用场景

### 自动攻击（飞机 AI）

飞机在自卫和自动锁定时使用 `FriendlyFireFilter.canAttack()` 判断：

- **自卫系统**：飞机在 STANDBY/ORBITING 状态下，自动反击接近的空中敌对目标
- **反潜探测**：反潜机高亮水下敌对目标
- **自动锁定**：锁定档位为"最近"、"最强"时，过滤友军

### 手动锁定（火控系统）

玩家通过火控终端或命令锁定目标时使用 `FriendlyFireFilter.canPlayerTarget()`：

- **禁止自锁**：玩家不能锁定自己
- **友军保护**：玩家不能锁定自己的召唤物（除非队伍允许友伤）
- **宽松规则**：允许锁定坐标、中立生物等非敌对目标（用于演习、测试）

## 数据包自定义

### 添加友方实体

创建数据包 `data/<namespace>/tags/entity_type/friendly_entities.json`：

```json
{
  "replace": false,
  "values": [
    "modid:custom_friendly_mob"
  ]
}
```

### 添加敌对实体

创建数据包 `data/<namespace>/tags/entity_type/hostile_entities.json`：

```json
{
  "replace": false,
  "values": [
    "modid:custom_enemy_mob"
  ]
}
```

### 覆盖默认规则

设置 `"replace": true` 可完全覆盖模组的默认标签：

```json
{
  "replace": true,
  "values": [
    "minecraft:zombie",
    "minecraft:skeleton"
  ]
}
```

## 多人游戏支持

### PvP 场景

默认情况下，飞机不会攻击其他玩家。如需启用 PvP：

1. **队伍对抗**：创建多个队伍，不同队伍的飞机会互相攻击
2. **标签标记**：通过数据包将 `minecraft:player` 加入 `hostile_entities` 标签

### 合作场景

同队伍的玩家可以：
- 共享火控目标（通过编队系统）
- 飞机互不干扰（自卫系统忽略友军飞机）
- 联合攻击共同目标（集火模式）

## 调试与测试

### 查看实体队伍

```mcfunction
/team list
/team option <队伍名> friendlyFire
```

### 测试敌我识别

1. 召唤测试实体
2. 召唤飞机并观察是否自动攻击
3. 调整标签或队伍设置
4. 重新加载数据包（`/reload`）

## 未来扩展

可能的增强方向：

- **阵营系统**：自定义数据组件标记阵营（红方/蓝方）
- **IFF 信号**：特定物品或方块作为友方识别标记
- **动态敌对**：根据玩家行为动态调整敌对关系（声望系统）
- **视觉反馈**：友军发光绿色，敌军发光红色
