# 命中反馈系统

## 概述

为不挠的舰载机模组添加了命中和击杀反馈功能，玩家可以实时看到飞机武器命中敌人的提示信息。

## 功能特性

- **实时反馈**：当飞机的武器命中或击杀目标时，玩家会收到字幕式通知
- **信息显示**：显示格式为 `[飞机名称] 命中/击杀 [目标名称]`
- **按玩家开关**：默认开启，玩家可选择关闭
- **持久化管理**：玩家下线时自动清理状态

## 实现细节

### 核心类

1. **HitNotifier** (`com.indomitable.carrieraircraft.combat.HitNotifier`)
   - 管理每个玩家的通知开关状态
   - 提供静态方法发送通知消息
   - 玩家下线时自动清理

2. **BombEntity 增强**
   - 添加了飞机信息追踪（名称和 UUID）
   - 添加了所有者信息（玩家 UUID）
   - 在爆炸伤害目标时发送反馈消息
   - 正确设置伤害来源为飞机实体

3. **AircraftEntity 增强**
   - 添加了 `getOwner()` 方法获取所有者实体
   - 投弹时自动设置弹药的飞机和所有者信息

### 消息格式

中文：
- 命中：`%s 命中 %s`（如：B-25轰炸机 命中 僵尸）
- 击杀：`%s 击杀 %s`（如：B-25轰炸机 击杀 僵尸）

英文：
- 命中：`%s Hit %s`（如：B-25 Bomber Hit Zombie）
- 击杀：`%s Killed %s`（如：B-25 Bomber Killed Zombie）

### 翻译键

- `message.indomitablecarrieraircraft.weapon_hit` - 命中消息
- `message.indomitablecarrieraircraft.weapon_kill` - 击杀消息
- `entity.indomitablecarrieraircraft.aircraft` - 通用飞机名称（当无法获取具体名称时使用）

## 技术要点

### 伤害来源处理

为了让 AI 正确反击飞机的所有者，使用了以下策略：

```java
Entity damageSource = this; // 默认是弹药实体本身
if (sourceAircraftUUID != null && level() instanceof ServerLevel sl) {
    Entity aircraft = sl.getEntity(sourceAircraftUUID);
    if (aircraft != null) {
        damageSource = aircraft; // 使用飞机作为直接伤害来源
    }
}
target.hurt(this.damageSources().explosion(damageSource, owner), scaledDamage);
```

这样设置后：
- 第一个参数（直接来源）是飞机实体，让 AI 可以看到并反击飞机
- 第二个参数（根本来源）是玩家，让仇恨最终指向玩家

### NBT 序列化

弹药实体正确保存和加载以下信息：
- `OwnerUUID` - 所有者 UUID
- `SourceAircraftUUID` - 飞机 UUID
- `SourceAircraftName` - 飞机名称（JSON 序列化的 Component）

### 事件集成

在 `ServerGameEvents.onPlayerLoggedOut` 中添加了清理逻辑：

```java
HitNotifier.onPlayerLogout(playerId);
```

## 未来扩展

2. **网络同步**：添加网络包允许客户端请求切换通知状态
3. **空战反馈**：为前射机枪和自卫炮塔也添加类似反馈
4. **统计信息**：跟踪每架飞机的命中率和击杀数

## 参考

本实现参考了皮兰港模组的 `HitNotifier` 系统，但做了以下调整：
- 适配了不挠的舰载机的实体结构
- 处理了 `BombEntity` 不继承 `OwnableEntity` 的问题
- 添加了飞机信息的序列化支持
