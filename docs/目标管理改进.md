# 目标管理功能改进

**日期**: 2026-07-10

## 改进概述

将控制终端的目标管理从单一"打击坐标"输入改进为完整的目标列表管理系统，并优化了物品交互逻辑。

## 主要变更

### 1. 控制终端 GUI 改进

#### 主界面右栏变更
- **原设计**：显示"打击坐标"标题 + X/Y/Z 输入框 + "添加打击目标"按钮
- **新设计**：
  - 显示"目标列表"标题
  - 列出所有已添加的目标（最多 4 个）
    - 实体目标显示橙色标记
    - 坐标目标显示红色标记
    - 显示坐标信息
    - 每个目标右侧有删除按钮（×）
  - 底部添加两个按钮：
    - "清空全部目标"：清除所有已添加的目标
    - "手动添加坐标"：进入手动坐标输入界面

#### 新增手动坐标界面
- 点击"手动添加坐标"按钮进入
- 显示：
  - X/Y/Z 坐标输入框
  - "添加打击目标"按钮
  - "← 返回"按钮
- 输入坐标后点击"添加打击目标"即可添加

### 2. 控制终端物品交互改进

#### 原交互逻辑
- 右键：打开 GUI
- 潜行 + 主手右键：快速锁定目标（优先实体，无实体时锁定方块）

#### 新交互逻辑
- **主手右键（非潜行）**：
  - 如果瞄准实体 → 添加实体目标
  - 如果未瞄准实体 → 打开 GUI
- **主手右键（潜行）**：
  - 添加方块坐标目标
- **副手右键**：
  - 打开 GUI

### 3. 网络协议

使用现有的 `ManageTargetsPayload` 网络包，支持：
- `CLEAR_ALL`：清空所有目标
- `REMOVE_BY_INDEX`：删除指定索引的目标

### 代码关键点

#### 目标列表渲染
```java
List<ControlTerminalMenu.TargetInfo> targets = menu.targetList();
int ty = MAP_Y + 14;
for (int i = 0; i < targets.size() && i < 4; i++) {
    ControlTerminalMenu.TargetInfo target = targets.get(i);
    Vec3 pos = target.position();
    int rowY = ty + i * 14;

    // 目标类型标记
    int markerColor = target.isEntity() ? MAP_TARGET_ENT : MAP_TARGET;
    g.fill(RIGHT_X + 2, rowY + 1, RIGHT_X + 4, rowY + 9, markerColor);

    // 坐标文本
    String coordText = String.format("%.0f,%.0f,%.0f", pos.x, pos.y, pos.z);
    g.drawString(font, coordText, RIGHT_X + 7, rowY, TEXT_COLOR, false);

    // 删除按钮
    int deleteX = RIGHT_X + RIGHT_W - 12;
    boolean hover = mouseX >= deleteX && mouseX < deleteX + 10
            && mouseY >= rowY && mouseY < rowY + 12;
    g.drawString(font, "×", deleteX, rowY, hover ? 0xFFFF5555 : DIM_TEXT, false);
}
```

#### 实体/方块分离锁定
```java
// 实体优先
private boolean quickLockEntityTarget(ServerPlayer player) {
    EntityHitResult entityHit = ProjectileUtil.getEntityHitResult(...);
    if (entityHit != null) {
        FireControlTarget target = FireControlTarget.entity(entityHit.getEntity());
        FireControlSystem.getInstance().addTarget(player, target);
        return true;
    }
    return false;
}

// 方块坐标
private void quickLockBlockTarget(ServerPlayer player) {
    HitResult blockHit = player.pick(MAX_TARGET_DISTANCE, 0, false);
    if (blockHit != null && blockHit.getType() != HitResult.Type.MISS) {
        FireControlTarget target = FireControlTarget.position(level, blockHit.getLocation());
        FireControlSystem.getInstance().addTarget(player, target);
    }
}
```

## 用户体验改进

### 之前的问题
1. 无法查看已添加的目标列表
2. 无法单独删除某个目标
3. 添加实体和方块目标的交互不够直观
4. 坐标输入框占据主界面空间

### 改进后的优势
1. ✅ 清晰的目标列表展示，区分实体/坐标目标
2. ✅ 可以单独删除每个目标或一键清空
3. ✅ 直观的物品交互：直接右键锁定实体，蹲下右键锁定方块
4. ✅ 手动坐标输入独立为子界面，主界面更简洁
5. ✅ 删除按钮悬停高亮，交互反馈清晰
